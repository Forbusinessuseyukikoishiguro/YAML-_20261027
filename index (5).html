新卒向け 開発環境構築ガイド

1人で開発環境を整えるための章ページです。章ごとに「完了の目安」を確認して進んでください。

  • 必須 必ず行う章
  • 構築済みならスキップ可 確認チェックがすべてはいなら飛ばせる
01

準備を確認する

この章でやること
パソコンの状態と、必要なアカウントを確認します。
所要時間の目安
約15分
完了の目安
下の4項目がすべて「はい」になる
  1. Windowsの更新が完了しているか確認する（設定 → Windows Update）。
  2. 管理者として操作できるアカウントか確認する。できない場合は情報システム担当に相談する。
  3. 社内のアカウント（メール・社内サイト）でログインできることを確認する。
  4. ディスクの空き容量が十分（目安：20GB以上）あるか確認する。
必須：この章は飛ばせません。
02

エディタ（VSCode）を入れる

この章でやること
文字を書いて編集するためのエディタ（VSCode）をインストールします。
所要時間の目安
約15分
完了の目安
VSCodeが起動し、左側にメニューが表示される
  1. 公式サイトからWindows版のインストーラーをダウンロードする。
  2. インストーラーを実行し、表示される項目は既定のまま進める。
  3. インストール後、VSCodeを起動して画面が表示されることを確認する。

構築済みの方はスキップ可

  • VSCodeが起動する
  • 日本語の表示が崩れていない
  • 拡張機能の画面（左側の四角いアイコン）を開ける

すべて「はい」なら次の章へ進んでください。1つでも「いいえ」なら、この章を行ってください。

03

Gitを入れて設定する

この章でやること
変更履歴を管理するGitをインストールし、名前とメールアドレスを設定します。
所要時間の目安
約20分
完了の目安
ターミナルで git --version と入力し、バージョンが表示される
  1. 公式サイトからWindows版のGitをダウンロードし、インストールする（項目は既定のまま）。
  2. VSCodeのターミナルを開き、git --version と入力して Enter を押す。
  3. 次の2行で、自分の名前とメールアドレスを設定する（<名前> などは自分の情報に置き換える）。
git config --global user.name "<名前>"
git config --global user.email "<メールアドレス>"

構築済みの方はスキップ可

  • git --version でバージョンが表示される
  • git config --global user.name で自分の名前が表示される

すべて「はい」なら次の章へ進んでください。

04

Dockerを動かす

この章でやること
コンテナを動かす仕組み（Docker）を準備し、動作を確認します。
所要時間の目安
約30分（初回の起動には時間がかかります）
完了の目安
ターミナルで docker run hello-world を実行し、「Hello from Docker!」が表示される
  1. 公式サイトからDocker Desktopをダウンロードし、インストールする。
  2. インストール後、Docker Desktopを起動し、表示が「実行中」になるまで待つ。
  3. ターミナルで docker run hello-world を実行する。
docker run hello-world
「Cannot connect to the Docker daemon」と出た場合：Docker Desktopが起動しているか確認してください。起動直後は数分待つ必要があります。

構築済みの方はスキップ可

  • docker run hello-world が成功する
  • Docker Desktopが社内ルールに沿った設定になっている（不明な場合は担当者へ確認）

すべて「はい」なら次の章へ進んでください。

05

動作確認をする

この章でやること
ここまでの環境が正しく動くかを、まとめて確認します。
所要時間の目安
約10分
完了の目安
下の3つのコマンドがすべて成功する
  1. ターミナルで code --version を実行する（VSCodeのコマンド）。
  2. git --version を実行する。
  3. docker --version を実行する。
code --version
git --version
docker --version
必須：この章は飛ばせません。3つすべてが成功したら完了です。
06

困ったときは

エラーが出たら、まず次を確認してください。

  1. エラーメッセージの全文を控える（一部だけでは原因が分かりにくいため）。
  2. どの章のどの手順で起きたかを確認する。
  3. その章の「完了の目安」が満たされているかを確認する。
  4. 解決しない場合は、エラー全文と実行したコマンドを添えて担当者に相談する。

焦らなくて大丈夫です。エラーは環境構築でよく起きることで、確認の手順を一つずつ進めれば解決できます。

※ 本ガイドの手順は作成時点の一般的な操作です。インストーラーの画面や社内ルールが異なる場合は、担当者の指示を優先してください。
